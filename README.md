# おばあちゃんホーム / Grandma Home

**よく使う5つの機能を、大きな固定ボタンで開くAndroidホームアプリ。**

スマートフォンの操作に不慣れな人が、いつもの機能にたどり着きやすいホーム画面を目指した小さなプロジェクトです。ボタンの移動・削除・サイズ変更の機能を設けず、日常の画面をシンプルにしています。

Androidの「ランチャー」（ホームボタンを押すと表示されるアプリ）として動きます。既存のLINEやカメラなどを開く入口を提供します。

```text
            13:30
       9月22日 火曜日

       [ LINE ] [カメラ]
       [ 写真 ] [連絡先]
       [     電話     ]

          電池 83%
```

上記は説明用の表示例です。実際の時計・日付・電池残量は自動更新します。

## できること

- LINE、カメラ、写真、連絡先、電話への大きなボタン。
- ボタン配置を固定。長押ししても編集メニューを開きません。
- 日本語の時計・日付・電池残量。時計は **Asia/Tokyo（日本時間）固定**です。
- ホーム画面のステータスバーを通常は非表示にし、時計などの重複を減らします。スワイプによる一時表示は可能です。
- 時計を5回続けてタップすると設定メニューを表示。Android設定、Wi-Fi、Playストア、ホームアプリの切り替えを開けます。

## できないこと・大事な制約

- **利用できるアプリを完全に制限する仕組みではありません。** 通知、履歴、リンク、共有メニューなどから別のアプリへ移動できます。
- **時計の5回タップは誤操作を減らすための入口で、認証ではありません。** PINはなく、操作を知っている人なら設定を開けます。家族だけにアクセスを保証するものではありません。
- 画面ロック、遠隔ロック、位置追跡、遠隔消去は実装していません。AndroidやGoogleの設定とは別です。このアプリは端末の画面ロックを変更しません。
- アプリの追加・並べ替え、ボタンの行き先変更は現時点では画面上からできません。
- カメラ・写真・電話など、開いた先のアプリの画面は簡略化しません。
- 高齢者全般に対する使いやすさや、すべての端末での動作を保証するものではありません。利用する方と一緒に実機で確かめてください。

## 使い始める

現時点では**ソースコードの公開**です。Playストア配信や署名済み配布APKは用意していません。Android Studioでビルドしてインストールします。

1. 下の開発手順でアプリをビルドし、端末にインストールします。
2. LINEとGoogleの[Gallery](https://play.google.com/store/apps/details?id=com.google.android.apps.photosgo)を、必要に応じて別途インストールします。
3. 「おばあちゃんホーム」を開き、時計を5回続けてタップします。タップ間隔が1.5秒を超えると数え直しになります。
4. 「ホームアプリに設定／解除」から「おばあちゃんホーム」を選びます。
5. ホームボタンで戻り、5つのボタンが目的のアプリを開くことを確認します。

**元に戻すには：** 時計を5回タップ →「ホームアプリに設定／解除」→ 元のホームアプリを選択します。Android設定の「デフォルトのアプリ」→「ホームアプリ」からも変更できます。名称は端末によって異なります。

### 各ボタンの行き先

| ボタン | 開くもの | 補足 |
| --- | --- | --- |
| LINE | LINE | 別途インストールが必要です |
| カメラ | 端末が選択するカメラアプリ | QRコード対応などはカメラ側に依存します |
| 写真 | Google Gallery | LINEの写真は、先に端末へ保存してください |
| 連絡先 | 連絡先を表示できるアプリ | 端末によって選択画面が出る場合があります |
| 電話 | ダイヤル画面 | ボタンを押しただけで発信しません |

対応アプリがない場合はメッセージを表示します。Galleryが写真を表示するための権限は、Gallery側で利用者が設定します。

## 開発・ビルド

### 必要な環境

- Android Studio（このプロジェクトのAndroid Gradle Plugin 9.4.1に対応した環境）
- Android SDK Platform 37
- Gradle 9.6.0（同梱のGradle Wrapperで実行）
- Gradleデーモン用JDK 25（`gradle/gradle-daemon-jvm.properties`で指定）
- 実行対象はAndroid 8.0 / API 26以上。compileSdk / targetSdkは37です。

ビルド環境の番号と、アプリを動かせるAndroidの最低バージョンは異なります。依存ライブラリの取得にはインターネット接続が必要です。指定バージョンが取得できない環境では、その環境でのビルドは未確認です。

### Android Studioを使う

1. このリポジトリを取得してAndroid Studioで開きます。
2. SDK ManagerでAndroid SDK Platform 37を用意します。
3. Gradle Syncを実行します。SDKの場所など、各PCの設定はローカルで指定してください。
4. USBデバッグを有効にした検証端末、またはエミュレーターを選び、Runを実行します。

### コマンドラインを使う

`JAVA_HOME`と`ANDROID_HOME`を自分の環境に合わせて設定します。SDKの場所を`local.properties`に設定する方法もありますが、そのファイルは公開しないでください。

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug
```

Windowsでは`./gradlew`の代わりに`gradlew.bat`を使います。

生成されるAPK：`app/build/outputs/apk/debug/app-debug.apk`

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

デバッグAPKは各開発環境の鍵で署名されます。別の鍵で署名された同じアプリが端末にある場合、上書きできません。既存のアプリを削除すると設定が失われる可能性があるため、検証用の端末を使ってください。独自に配布する場合はアプリIDと署名・更新方法を管理してください。

### テスト

- 単体テスト：時計のタップ回数と間隔による設定メニューを開く条件。
- UIテスト：5つのボタンと電池表示、長押しで編集しないこと、ホームアプリとしての登録、設定メニューの表示条件。
- UIテストAPKのビルド：`./gradlew :app:assembleDebugAndroidTest`
- 検証用エミュレーターでのUIテスト実行：`./gradlew :app:connectedDebugAndroidTest`

`connectedDebugAndroidTest`はテスト用アプリのインストール・アンインストールを伴います。日常利用中のホームアプリを設定した端末での実行は避けてください。

開発時にAQUOS wish3 / Android 15で起動、ホームへの切り替え、外部アプリ起動を確認しています。機種・画面サイズ・文字サイズによって表示が変わり、大きな文字設定ではスクロールが必要な場合があります。公開用コピーの検証結果は[検証記録](docs/VALIDATION.md)を参照してください。

## ソースの構成

- `MainActivity.kt`：ホーム画面、電池表示、外部アプリ起動、設定メニュー。
- `ClockTapGate.kt`：時計の連続タップ判定。
- `AndroidManifest.xml`：ホームアプリとしての登録と、起動先アプリの照会。
- `app/src/test/`・`app/src/androidTest/`：単体テストとUIテスト。

詳しくは[プライバシーと安全性](docs/PRIVACY.md)を参照してください。
